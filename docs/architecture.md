# MineGuard C1 设计与集成

## 车体模型

`urdf/mineguard_c1.urdf` 定义车体、惯性、碰撞体、四个车轮及传感器安装关系。`meshes/` 保存项目车身外观，碰撞与惯性沿用 C1。车轮半径 0.12 m，左右轮中心距 0.48 m。

## 驱动与传感器

`src/course_effort_drive.cpp` 把车体速度换成左右目标轮速，读取四个关节的实际转速，用 PI 控制产生扭矩。每轮扭矩限幅为 ±12 N·m，速度请求断流后目标归零。控制只读关节速度；轮式里程计会受滑移影响。本包提供机器人内部 TF，使用外部定位时由外部节点发布定位坐标系到车体的变换。

`src/lio_lidar.cpp` 读取 Gazebo 32 线激光射线结果，发布带线号和时间字段的 PointCloud2。它是同一时刻采样的仿真快照。IMU 与激光共址同轴，RGB-D 相机提供前向图像和深度。

## 课程项目中的上层架构

1. 激光与 IMU 接入 LIO-SAM，估计三维位置与姿态并更新地图。
2. 从三维观测提取地面通行信息，供 Navfn 和基于 TrajectoryPlannerROS 的局部规划使用。
3. 任务控制按顺序执行给定目标。速度请求经过保护层后传给底盘，停车与事件记录由上层负责。
4. 禁入标志触发停车时保存图像和机器人发现位置。RGB-D 也可用于离线地图着色。

此仓库提供模型、驱动、传感器与启动入口。LIO-SAM、Navfn 和 TrajectoryPlannerROS 是课程项目采用的组件；接入这些组件时，请在自己的场景中配置定位、规划及相应话题。
